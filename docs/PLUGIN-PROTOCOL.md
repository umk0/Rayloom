# Lumen plugin bridge v1

Bridge не изменяет OpenRGBPluginInterface или Plugin API 5. Ядро загружает стандартный Qt-плагин, вызывает Load и создаёт его скрытый GetWidget. Electron работает с принадлежащим ему процессом ядра через QLocalServer с UserAccessOption, случайным именем pipe и токеном на каждый запуск. Произвольные сетевые клиенты этот интерфейс не получают.

## Нативный адаптер

В существующем OnSDKCommand зарезервирован идентификатор `0x4C554D31`. Payload — UTF-8 JSON с `method` и параметрами. Ответ — UTF-8 JSON `{ "result": ... }` либо `{ "error": "..." }`. Буфер выделяется через `new unsigned char[]`, длина возвращается через `pkt_size`; ядро освобождает его через `delete[]`. Общая реализация: `plugins/LumenProtocol.h`. Прочие SDK-команды должны сохранять прежнюю обработку плагина.

Пример: `{"method":"config.get"}`. Изменение настроек выполняется отдельным `config.set`, проверяет весь ввод перед применением и возвращает актуальное состояние. Ошибки возвращаются как JSON и не должны выходить через ABI как исключения. Запросы выполняются в главном Qt-потоке; фоновые сетевые callbacks отправляют работу туда через queued invocation. При выгрузке остановить таймеры и присоединить рабочие потоки.

У Effects: `catalog`, `scene.get`, `scene.apply`, `start`, `stop`, `globals.get/set`, `screens`, `screen.capture`, `shaders`, `shader.read/save`, `diagnostics`, `blendModes`. Формат scene — исходный Effects v2. Каталог содержит поля, диапазоны, enum и исходные настройки. Индивидуальные алгоритмы продолжают выполняться в исходных классах Effects.

## Панель Electron

Renderer не имеет Node.js и не подключается к pipe напрямую. Preload предоставляет ограниченный `window.lumen`, main проверяет отправителя, размер и allowlist методов. Для нового плагина необходимо зарегистрировать его ID и методы в `desktop/main.cjs`, подключить React-панель и реализовать нативный адаптер. Существующие примеры: `src/PluginPanels.tsx`, `src/VisualMapPanel.tsx`, `src/EffectEditor.tsx`.

Это контракт данного source fork, а не обещание автоматического исполнения произвольного внешнего JavaScript. Динамический установщик веб-панелей ещё не реализован. Для совместимого старого DLL без адаптера остаётся нативный ABI; его QWidget невозможно автоматически преобразовать в React.

## Регрессии

Не менять IID, API-номер или виртуальные методы OpenRGB ради интерфейса Electron. Проверять загрузку оригинальной Effects DLL (`test:core`), новые DLL (`test:plugins`), закрытие без принудительного завершения, восстановление настроек и неизвестные/невалидные команды. Совпадение номера API само по себе не гарантирует совместимость Qt и C++ ABI.
