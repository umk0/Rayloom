# Параметры эффектов Rayloom

## Что видит пользователь

После выбора эффекта появляется отдельная секция **«Настройки · название эффекта»**. В ней только значения, которые использует этот алгоритм. У «Призмы» — скорость и размер рисунка; цветовую палитру задаёт алгоритм. У «Одного цвета» — только цвет. У «Дыхания» — цвет и скорость. Общая яркость, группа устройств и частота обновления относятся ко всей сцене и расположены отдельно.

Авторские параметры SDK и дополнительные нативные параметры сохраняются отдельно в `config.effectParameters[effectId]`. При переключении между эффектами эти значения не смешиваются. Прежние стандартные цвет, скорость и масштаб остаются совместимыми полями сцены. Изменения применяются общей кнопкой «Применить изменения»; превью получает ту же конфигурацию.

## Декларативные плагины SDK

Формат `schemaVersion: 1` совместим со старыми manifest. Новое необязательное поле `effects[].parameters` содержит до 32 контролов:

```json
{
  "id": "example",
  "name": "Свет",
  "parameters": [
    {"key":"tint","type":"color","label":"Цвет свечения","default":255},
    {"key":"level","type":"number","label":"Сила свечения","min":0,"max":1,"step":0.05,"default":0.5},
    {"key":"enabled","type":"boolean","label":"Свет включён","default":true},
    {"key":"mode","type":"select","label":"Режим","default":1,"options":[{"value":1,"label":"Мягкий"},{"value":2,"label":"Яркий"}]}
  ],
  "rgb": [
    {"op":"mul","args":[{"param":"tint","channel":"r"},{"param":"level"}]},
    {"op":"mul","args":[{"param":"tint","channel":"g"},{"param":"enabled"}]},
    {"op":"mul","args":[{"param":"tint","channel":"b"},{"param":"mode"}]}
  ]
}
```

Этот фрагмент — определение одного эффекта внутри manifest; полный устанавливаемый пакет: [`parameter-pulse`](../sdk/examples/parameter-pulse/manifest.json).

| Тип | Обязательные поля | Значение в выражении |
|---|---|---|
| `number` | `min`, `max`, `default`; `step` по умолчанию 1 | `{"param":"level"}` |
| `boolean` | `default`: `true` или `false` | 1 или 0 |
| `select` | `options: [{label,value}]`, `default` из списка | Числовое `value` |
| `color` | `default`: целое RGBColor 0…16777215 | `{"param":"tint","channel":"r"}`; каналы `r`, `g`, `b` в диапазоне 0…1 |

Цвета упакованы как `0xBBGGRR`: красный — `255`, зелёный — `65280`, синий — `16711680`. HEX в интерфейсе отображается привычным `#RRGGBB`.

Все контролы содержат `key` (буква, далее буквы/цифры/`_`/`-`, до 48 символов) и понятную пользователю `label` до 100 символов. Необязательный `help` до 500 символов объясняет результат изменения. У чисел конечные `min < max`, диапазон в пределах ±1 000 000, положительный шаг. Изменённые значения ограничиваются диапазоном и шагом. `select` содержит 1–32 уникальных числовых варианта.

Загрузчик отклоняет неизвестные типы, дубли ключей, опасные ключи, некорректные диапазоны, значения по умолчанию вне диапазона, необъявленные параметры в формулах. **Объявленный параметр обязан присутствовать хотя бы в одном RGB-выражении.** Это не доказывает художественную полезность параметра, но исключает полностью забытые автором контролы. Проверка результата на разных значениях остаётся частью разработки эффекта.

Старые переменные `speed` и `scale` остаются доступны. Их стандартные контролы появляются только если формула действительно ссылается на соответствующую переменную. Параметр `color` автоматически не добавляется: цвет должен быть явно описан автором. Частота кадров и общая яркость применяются движком отдельно.

## Нативные эффекты

Rayloom строит контролы из фактического описания эффекта: диапазонов скорости и второго слайдера, количества пользовательских цветов, `CustomSettings` и их метаданных. Поддержаны числа с известными границами, булевы значения, перечисления, цвета и палитры. Файлы, шейдерные программы, массивы сложных объектов и композиции слоёв остаются в редакторе эффекта; интерфейс показывает явный переход туда.

Кнопка **«Расширенная библиотека»** открывает отдельную нативную сцену. Она не редактирует автоматически выбранную пространственную карточку. Следующий этап UX/SDK: единый редактор сложных источников, возвращающий параметры текущему эффекту с сохранением группы, проекции и существующего черновика. До реализации такого протокола переход явно описан как работа с отдельной сценой.

Сохранённые значения применяются только по разрешённым путям из описания эффекта. Ключ из IPC не превращается в произвольный путь JSON. Неизвестные устаревшие ключи игнорируются; неверное выбранное значение показывается как значение по умолчанию, чтобы сменившийся список аудиоустройств не ломал экран настроек.

Основные стандартные поля `color`, `speed`, `scale` сохраняют совместимость прежних сцен. Несколько пользовательских цветов сохраняются как палитра; в старой сцене первый цвет берётся из прежнего `config.color`.

## HTML Canvas

HTML-эффекты уже объявляют собственные контролы через `<meta property="…">`; [контракт Canvas](CANVAS-EFFECTS.md) сохраняется. Эти значения доступны через `window.lumenEffect.getState().parameters`. Общий смысл тот же: автор описывает только используемые параметры. В шаблоне «Полярное сияние» удалён неиспользуемый контрол цвета. Форматы SDK JSON и HTML metadata пока различны; это два адаптера параметров, а не единый формат пакетов.

## Проверка реализации

`tests/effect-parameters.test.mjs` сравнивает реальные кадры всех 13 встроенных эффектов при изменении каждого общего параметра, проверяет native allowlist, раздельное сохранение значений, совместимость старого SDK, применение новых настроек через production frame renderer и отказ от невалидных схем. Это тесты алгоритма и контракта; физическое устройство ими не проверяется.
