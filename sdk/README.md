# Rayloom SDK v1

SDK для новых пространственных эффектов и шаблонов LED. Это исполняемый контракт, а не только предложение архитектуры: пример Reactor проверяется загрузчиком, появляется в Electron и отправляет кадры через ядро OpenRGB.

Каждый эффект может объявить **свои параметры**: цвет, число с диапазоном и шагом, переключатель, выбор режима. Интерфейс показывает только объявленные настройки. Пример с реально работающими контролами: [`examples/parameter-pulse/manifest.json`](examples/parameter-pulse/manifest.json). Подробный контракт и путь значения до кадра: [Параметры эффектов](../docs/EFFECT-PARAMETERS.md).

Для эффектов на JavaScript доступен встроенный [HTML Canvas редактор](../docs/CANVAS-EFFECTS.md): отдельный renderer, параметры, игровые события и проекция на группу устройств. Декларативный SDK ниже остаётся способом описывать формулы непосредственно в мировых XYZ-координатах.

## Первый плагин

1. Скопируйте папку `sdk/examples/reactor`.
2. Задайте уникальный `id` вида `com.example.mylights`, имя, автора и версию.
3. Измените три выражения `rgb`. Результат каждого канала ограничивается диапазоном 0…1.
4. Выполните `node sdk/validate.mjs путь/manifest.json`.
5. В приложении: **Расширения → Установить из папки**. Устанавливается проверенный manifest, не произвольные файлы.
6. Выберите эффект в **Моя подсветка → Показать все → Сообщество**, настройте его параметры, назначьте группу, нажмите «Включить».

Рекомендуемый цикл разработки — виртуальная студия. Приложение показывает реальные выходные цвета виртуального контроллера. Настройки аппаратного и виртуального режимов разделены.

## Контракт

```json
{
  "schemaVersion": 1,
  "id": "com.example.depth",
  "name": "Глубина",
  "version": "1.0.0",
  "author": "Example",
  "license": "GPL-2.0-or-later",
  "effects": [{
    "id": "depth",
    "name": "Глубина",
    "rgb": [
      {"op":"fract","args":[{"op":"div","args":[{"var":"z"},200]}]},
      0.3,
      {"var":"health"}
    ]
  }],
  "templates": [
    {"id":"ring-12","name":"Кольцо 12 LED","kind":"ring","count":12,"radius":60}
  ]
}
```

Формат выражения: число, `{"var":"имя"}` или `{"op":"операция","args":[...]}`.

| Переменная | Значение |
|---|---|
| x, y, z | Мировые координаты LED в мм после масштаба, поворотов X → Y → Z и переноса |
| t | Секунды с запуска эффекта |
| index | Индекс LED в выбранной группе; не идентификатор физического устройства |
| health, ammo | Последнее игровое значение 0…1; начальное значение 1 |
| speed | Скорость пользователя 0…10 |
| scale | Пространственный масштаб пользователя 1…2000 мм |
| brightness | Общая яркость 0…1; итоговая яркость применяется движком отдельно |

Бинарные операции: add, sub, mul, div, min, max. Унарные: sin, cos, abs, fract, clamp, sqrt. Углы sin/cos в радианах; clamp ограничивает 0…1; деление на ноль возвращает 0. Не умножайте RGB на brightness без необходимости: общая яркость будет применена ещё раз.

Максимум 32 эффекта и 64 шаблона в пакете. Выражение одного канала — не более 512 узлов и 16 уровней. Manifest — до 256 КБ. Загрузчик отклоняет неизвестные операции, переменные, повторные ID эффектов и недопустимые значения.

Шаблоны: line, ring, grid; count 1…4096, radius/spacing в мм, columns для матрицы. При применении пользователь задаёт первый физический LED. Шаблон не является подтверждением соответствия конкретной модели оборудования.

## Игровые события

Приёмник выключен по умолчанию. Включается в «Сцены и игры», слушает только 127.0.0.1:19421. POST /events:

```json
{"token":"LOCAL_TOKEN","event":{"name":"health","value":0.15}}
```

Допустимы health и ammo. Значение — конечное число 0…1. Токен создаётся локально в файле game-auth.json; в интерфейсе и журналах не выводится. Экспорт GSI-конфига содержит этот токен, поэтому конфигурацию нельзя публиковать как общий пример.

POST /gsi принимает auth.token, player.state.health (0…100), player.weapons.*.state=active, ammo_clip и ammo_clip_max. Экспортированный .cfg предназначен для игр с совместимым Game State Integration. Проверен HTTP-поток на синтетических данных, реальная игровая сессия пока не проверялась. Универсального автоматического API для всех игр нет: каждому семейству нужен адаптер.

Для встроенных пространственных эффектов флажок тревоги даёт красную пульсацию при health < 0.3, после восстановления возвращает базовый эффект. Плагины могут использовать health/ammo в собственных формулах. Нативные эффекты OpenRGB не получают этот override. Последнее событие сохраняется в памяти до нового события или перезапуска; автоматическое определение выхода из игры пока не реализовано.

## Выполнение и ограничения

- Manifest — данные. Нет eval, Node API, доступа к файлам/сети или произвольного JS.
- Интерпретатор кадров работает в отдельном worker фонового движка. Целевая частота задаётся в приложении, при незавершённой отправке кадр пропускается. Это не гарантия заданного FPS на любом оборудовании.
- До 128 компонентов и 16 384 LED в пространстве. Нативное ядро проверяет весь пакет адресов перед записью цветов.
- Одновременно активна одна пространственная сцена с выбранной группой. Запуск останавливает другие источники записи: Effects, Hardware Sync, E1.31, Scheduler, HTTP Hook и зарегистрированные Visual Map. Пользователь может снова включить их в расширенных инструментах, при этом пространственный движок останавливается.
- Пересекающиеся назначения одного физического LED получают цвет последнего компонента по порядку. Для независимых вентиляторов используйте непересекающиеся диапазоны.
- Произвольные веб-панели, исполняемые JS/Wasmtime-плагины, магазин, подписи пакетов, отдельные процессы для каждого плагина и горячая выгрузка нативных DLL не реализованы.

## Миграция из OpenRGB

Нативный путь и декларативный SDK дополняют друг друга:

1. Сохраните исходный Plugin API 5, IID, vtable и лицензию. Бинарник должен соответствовать платформе, компилятору и Qt.
2. Разделите алгоритм/состояние и видимую Qt-панель. В существующих портах скрытые Qt-виджеты пока сохраняются там, где на них завязана логика.
3. Добавьте JSON-методы через существующий OnSDKCommand, не расширяя ABI. Проверяйте вход, выполняйте действия Qt на его главном потоке. См. [PLUGIN-PROTOCOL.md](../docs/PLUGIN-PROTOCOL.md).
4. Перенесите настройки в React/HeroUI; добавьте узкий разрешённый IPC-контракт в main/preload, не открывайте renderer произвольный RPC или файловую систему.
5. Сохраните старые форматы профилей; обеспечьте остановку, повторное включение, отключение контроллера и завершение приложения.
6. Проверьте профиль, реальные выходные кадры на виртуальном устройстве, ошибки параметров и чистый выход ядра. После этого проверяйте конкретное оборудование.

Простой RGB-алгоритм можно переписать в формулы SDK. Аудиозахват, видео, сложный C++ и Qt невозможно автоматически перевести в этот ограниченный формат. Для них нужен нативный адаптер или будущий расширенный runtime.

Оригинальная неизменённая Effects DLL отдельно проверяется `npm run test:core`. Новые Electron-панели используют изменённые сборки семи плагинов. Это не обещание совместимости любых будущих ABI.
