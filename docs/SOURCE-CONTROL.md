# Публичные исходники Rayloom

13 ноября 2026 создан публичный [репозиторий Umk0/Rayloom](https://github.com/umk0/Rayloom).
В `main` опубликован исходный снимок Electron/React, ядра OpenRGB с изменениями
Rayloom, семи встроенных плагинов, SDK, тестов и сборочных скриптов. Базовые
upstream URL и commit ID записаны в `sources.lock.json`; лицензии включены.

Рабочая папка разработчика пока содержит восемь вложенных checkout и не
является самим Git checkout нового монорепозитория. Публикуемый снимок
собирается скриптом `scripts/export-public-source.mjs` в
`artifacts/source/Rayloom`. Скрипт исключает `.git`, профили, ключи,
промежуточные файлы Qt и бинарные сборки. Перед публикацией проведён поиск
персональных путей и типовых секретов. Прямой `git add .` в родительском
рабочем каталоге запрещён: там находятся другие проекты пользователя.

## Осталось до бинарного релиза

1. Воспроизвести renderer, ядро и семь DLL из публичного checkout на чистом
   Windows-окружении. Текущий виртуальный прогон подтверждает собранный здесь
   пакет, а не сборку с чистой машины.
2. Проверить лицензии всех vendored зависимостей и финальный список файлов.
3. Провести ручную установку Electron Setup, перенос существующего профиля и
   повышенной задачи Windows, обновление и откат. До этой проверки выпуск
   бинарного релиза на GitHub преждевременен.

Вложенные checkout сохраняют свою upstream-историю локально; первый коммит
публичного монорепозитория — полный снимок источников, а не импорт всей
истории каждого upstream-проекта.
