# HTML Canvas эффекты LumenRGB

В приложении откройте **Создать эффект**. Выберите пример, нажмите **Предпросмотр**, настройте параметры и затем **Включить на устройствах**. Код и последний кадр видны рядом; ошибка скрипта выводится под редактором. Черновик сохраняется автоматически. Библиотека хранится локально отдельно для аппаратной и виртуальной студии. Можно импортировать и экспортировать обычный `.html`.

HTML рисует изображение в отдельном Chromium renderer. Lumen получает кадр 128 × 128, проецирует координаты LED выбранной группы в XY/XZ/YZ, применяет общую яркость и калибровку каждого порта, затем отправляет цвета через OpenRGB. Пропорции пространства сохраняются. Отправка продолжает работать после ухода со страницы редактора.

```html
<!doctype html>
<meta property="speed" label="Скорость" type="number"
      min="0" max="10" step="0.1" default="1">
<meta property="color" label="Цвет" type="color" default="#a378ef">
<style>html,body{margin:0;overflow:hidden;background:#000}</style>
<canvas id="effect" width="128" height="128"></canvas>
<script>
const ctx = document.getElementById('effect').getContext('2d');
function draw(now) {
  const {parameters, events} = window.lumenEffect.getState();
  const t = now / 1000;
  ctx.fillStyle = events.health < .3 ? '#ff2020' : parameters.color;
  ctx.globalAlpha = 1;
  ctx.fillRect(0, 0, 128, 128);
  ctx.fillStyle = '#000000';
  ctx.globalAlpha = .35 + .35 * Math.sin(t * parameters.speed);
  ctx.fillRect(0, 0, 128, 128);
  requestAnimationFrame(draw);
}
requestAnimationFrame(draw);
</script>
```

Поддерживаются до 16 meta-параметров: `number`, `color`, `boolean`. Ключ `property` состоит из латинских букв, цифр и `_`, начинается с буквы. Значения доступны через `parameters`, игровые `health` и `ammo` — через `events`. Параметры обновляются без перезапуска HTML. Изменённый исходник запускается кнопкой предпросмотра или вывода.

Предпросмотр UI обновляется до 5 раз/с; это отдельный показатель от частоты отрисовки источника и отправки LED. Статичный canvas может не создавать повторные paint-события: последнее изображение остаётся активным. Целевая частота задаётся на главном экране; фактическая частота устройств зависит от их драйверов.

HTML ограничен 200 000 символами. В renderer отключены Node.js, IPC приложения, внешняя сеть, файловые загрузки, вложенные страницы, workers, новые окна и разрешения устройств. Доступ к оборудованию имеет только основной процесс. Зависший скрипт останавливается watchdog после отсутствия heartbeat более 3 секунд; редактор продолжает работать. Тесты проверяют это на настоящем Electron.

Это собственный HTML-контракт LumenRGB. Совпадение идеи Canvas и формы meta-тегов не означает полную совместимость с API или каталогом SignalRGB: сторонний эффект нужно проверить и адаптировать его параметры/ресурсы. Нативные OpenRGB DLL используют отдельный путь совместимости, описанный в [PLUGIN-MIGRATION.md](PLUGIN-MIGRATION.md).
