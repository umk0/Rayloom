# Перенос официальных плагинов

База: семь проектов из [каталога OpenRGB](https://openrgb.org/plugins.html), закреплённых в `sources.lock.json`. Все семь DLL собраны из изменённых исходников и загружаются в форк ядра. Рабочие панели находятся в Electron; Qt служит внутренней зависимостью нативных плагинов.

| Плагин | Панель Electron | Подтверждение |
|---|---|---|
| Effects 1.1 | Все 58 эффектов и их поля; сцены, пресеты, зоны, общие настройки; Layers, аудио/EQ, GIF, Ambient, GLSL | 58/58 загрузок, запуск 56 эффектов; GIF и Ambient отдельно, GLSL кадры и ошибки |
| Visual Map 1.0 | SVG-карта, перетаскивание, форма каждого LED, сетка, сохранение/загрузка, регистрация контроллера, фон и градиенты | Виртуальный контроллер появляется в ядре, градиент доходит до ленты, файлы градиентов сохраняются |
| Hardware Sync 1.0 | Датчики, интервалы, цветовые пороги, яркость, направление, заполнение, назначения зон | Синтетический датчик 50%, изменение цветов, восстановление правил после перезапуска |
| E1.31 Receiver 1.0 | Universes и маршрутизация каналов, multicast, автокарта, счётчики | Реальный локальный UDP-пакет изменяет RGB; быстрый старт/стоп и добавление/удаление виртуального устройства |
| HTTP Hook 1.0 | Адрес, порт, GET/POST, маршруты, профили, автозапуск | Локальный POST запускает сохранённую сцену |
| Scheduler 1.0 | Cron, пресеты, профиль, включение, следующий запуск, ручной запуск | Таймер запускает сцену; сохранение до завершения старта не дублирует задачи |
| Skin 1.0 | Темы Electron, палитра, импорт/экспорт, автозагрузка | Сохранение и восстановление палитры; QSS переносит только цвета |

## Форматы и границы

- Effects использует исходный JSON профиля версии 2. Импорт принимает отдельный профиль Effects и объект `plugins["OpenRGB Effects Plugin"]` из JSON-профиля OpenRGB. Сохранённые сцены зеркалируются через ProfileManager, поэтому доступны другим плагинам.
- Карты, градиенты, HTTP, расписание и E1.31 используют исходные менеджеры настроек. Каталог конфигурации приложения отдельный: существующие настройки OpenRGB автоматически не копируются. Аппаратные правила дополнительно сохраняются в `plugins/settings/LumenHardware.json`.
- Синтаксис cron — синтаксис исходного libcron, включая `?` для неиспользуемого дня недели/месяца; ежедневный пример: `0 0 20 * * ?`.
- QSS привязан к Qt. В Electron применяется извлечённая палитра, а не точная копия всех QSS-правил.
- Все 58 карточек соответствуют реальным конструкторам, а поля получаются из настроек и метаданных плагина. Автоматические прогоны не перебирают все сочетания каждого параметра.
- Аудиоэффекты и настройки входа проверены на загрузку/запуск; реакция на конкретный микрофон или loopback ещё требует проверки с источником сигнала.
- Реальные USB/SMBus-контроллеры, драйверы датчиков, аппаратный hotplug, сон/пробуждение, разные DPI и несколько GPU не сертифицированы этими тестами.
- API 5 и Qt ABI сохранены. Проверка одной оригинальной DLL не является доказательством совместимости всех исторических и будущих сторонних бинарников.
- Публичный установщик, автоматический загрузчик сторонних веб-панелей и изоляция аварий отдельных плагинов остаются отдельными этапами.
## Плагины LumenRGB и пространственные сцены

SDK v1, рабочий manifest, формулы RGB, шаблоны и игровой HTTP-контракт описаны в [sdk/README.md](../sdk/README.md). Старый нативный плагин сохраняет ABI 5 и получает JSON-адаптер и React-панель. Простой алгоритм можно перенести в декларативный SDK; произвольный C++ и Qt автоматически не конвертируются.

В 0.3 аппаратное обнаружение проверено на четырёх устройствах с семью загруженными DLL. Hardware Sync перечислил реальные источники; цветовые интеграционные тесты всё ещё выполняются на виртуальном контроллере. Полный отчёт — [VERIFICATION.md](VERIFICATION.md).
