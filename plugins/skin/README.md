# <img src="OpenRGBSkinPlugin.png" width="48" height="48" style="vertical-align: middle;"/> OpenRGB Skin Plugin

[![pipeline status](https://gitlab.com/OpenRGBDevelopers/OpenRGBSkinPlugin/badges/master/pipeline.svg)](https://gitlab.com/OpenRGBDevelopers/OpenRGBSkinPlugin/-/commits/master)

Customize your [OpenRGB](https://gitlab.com/CalcProgrammer1/OpenRGB) application style using Qt skin files (.qss) or selecting between the system's default theme and the Qt Fusion built-in theme.

## Features
  * Apply skins from the skins folder
  * Load skins from disk
  * Load the current skin automatically at startup
  
## Website

* Check out our website at [openrgb.org/plugin_skin](https://openrgb.org/plugin_skin.html)

## Installation

  * Pre-built binaries are available for the following platforms:
    * Windows
    * Linux (.so, .deb, and .rpm)
    * MacOS
  * Released versions are available to download on [OpenRGB.org](https://openrgb.org/plugin_skin.html).
  * Experimental (aka Pipeline) versions are available to download on [OpenRGB.org](https://openrgb.org/plugin_skin.html#pl).
  * The pre-built .so binaries are intended to be used with the OpenRGB AppImage builds and may not be compatible with OpenRGB installed from other sources.
  * Arch users can also install from the AUR for the [release](https://aur.archlinux.org/packages/openrgb-plugin-skin/) or [pipeline](https://aur.archlinux.org/packages/openrgb-plugin-skin-git/) version.
